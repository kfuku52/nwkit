`0a4cea2881cf0559f124f68b03d4b0203759bb67`, version 0.43.37.
This milestone adds bounded conditional age/Ne fitting, identifiability
diagnostics and an independent estimated-gene-tree pilot. The
[fixed-parameter milestone](MUL_MSC_VALIDATION.md) remains a separate historical
snapshot. See the [fitting guide](../guides/MUL_MSC_FIT.md) for the contract.

One disomic allopolyploid event is assumed. Species ages, H1 and candidate
scope are supplied; observed copies are conditioned on. This is not a WGD
test, full AlloppNET, DL+ILS, global identifiability proof or production
accuracy validation. Default D+L and fixed MSC remain unchanged.

## Identifiability and Numerical Evidence

- An analytic three-tip case with A and two unknown X homoeologs has
  `P(XX)=exp(-t)/3` and `P(AX)=1/2-exp(-t)/6` for each A-X topology, where
  `t=(2-age)/(2*Ne)`. Age 1/Ne 1 and age 0.5/Ne 1.5 give the same complete
  topology distribution. Both finite-difference steps returned sensitivity
  rank one for a two-parameter fit, marking it locally unidentified.
- Scaling all species ages, attachment age and Ne by 17 preserved the
  likelihood. Absolute time cannot be supplied by topology probabilities
  alone; Ne fitting requires externally specified generations.
- With fixed scale, analytic three-tip counts 90 A-X/10 X-X gave age
  `2+log(0.3)`; with fixed age, counts 80 concordant/10 each discordant gave
  Ne `-1/log(0.3)`. Fits matched these independent MLEs within `2e-5`.
- A full five-tip distribution across all 105 rooted binary topologies was
  generated by the independent all-pair gene-forest CTMC, not by sampling
  the production recurrence. With expected counts totaling 1,000 families,
  the joint fit recovered age 1 and Ne 0.5 within `2e-4`, sensitivity rank
  two, and every nuisance-refitted profile at or below the fitted maximum.
  This checks population-expectation fitting, not finite-sample accuracy.
- A flat two-X-tip fit and a boundary optimum withheld fitted points.
  Species-colored grouping matched raw-family likelihood sums, preserving
  every original family and its multiplicity.
- Each donor gets its own overlap between supplied age bounds and parental
  stems; an internal donor requiring age above 3 was retained alongside
  a leaf donor requiring age below 3. No shared initial age filtered them.

Diagnostics are deliberately limited: the sensitivity rank uses observed
patterns and normalized search coordinates at two local steps. Full rank is
not global identifiability, good precision, calibrated coverage or biological
model adequacy. Profiles are finite nuisance-refitted grids, not intervals.
The numerical solution is retained for reproducibility even when point
estimates are withheld; it is not a reported biological estimate.

## Independent Sequence/Tree Pilot

The [protocol and executable study](../../examples/mul-msc/README.md) were
defined before the full run. Seed `20261018`, two replicates of 100 independent
families for each of ten cases: **20 datasets, 2,000 family genealogies and
40 paired true/estimated-tree analyses**. No dataset or family was dropped.
The full run exited zero; all replicate fits completed.

```bash
env OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
  /tmp/nwkit-wgd-dev-20261001/bin/python \
  examples/mul-msc/conditional_pilot.py \
  --output /tmp/nwkit-msc-fit-pilot-20261002
```

Ancestry used msprime's standard coalescent, global ploidy 2, and one haploid
sample per diploid/subgenome via `SampleSet(ploidy=1)`; the distinction is
documented in [msprime's ploidy API](https://tskit.dev/msprime/docs/latest/ancestry.html#ploidy).
JC69 simulations generated 600-site alignments including invariant sites,
at rate 0.003/site/generation. This uses the independent
[msprime mutation simulator](https://tskit.dev/msprime/docs/latest/mutations.html),
not NWKIT topology draws. Homoeolog labels were randomly flipped.
Biopython NJ with JC69-corrected distances and midpoint rooting estimated
trees without consulting their true roots. It is not IQ-TREE ML or an
integration over sequence/gene-tree uncertainty.

Fitted MSC received species ages and bounds age `(0.1,1.9)`, Ne `(0.1,10)`,
grid size 3 and three starts, **not true age or Ne**. Standard truth age was
0.7, and Ne was 0.5 or 5. D+L and MSC received identical families and candidate
sets. This still gives MSC information unavailable to D+L: known species
ages and its conditional MSC model. The D+L comparison is parent-only,
excluding baseline/autopolyploidy, not the full default workflow.

The ghost proxy changes donor separation to 1.3 while holding Ne constant
and introducing no founder jump. It is observationally a direct attachment
at 1.3, not a full ghost-network simulation. Its error is measured against
1.3; optimizing attachment must not be called recovery of biological
hybridization age 0.7. The first replicate selected the wrong donor in both
views, despite the separation lying inside the search interval.

The omitted-parent case selected A in all four analyses. One estimated-tree
fit was interior and locally distinguishable despite selecting a false
parent (Ne 9.691463, attachment 1.206578). This directly demonstrates that
neither a unique maximum nor full local rank establishes model adequacy or
that the true parent was among the candidates. The mode has no calibrated
rejection/support test for this situation.

## CLI and Failure Contracts

Executed cases covered explicit unit/mode conflicts, bounds, evaluation
caps, invalid family weights and injected total optimizer nonconvergence.
They fail without a grid/fixed-parameter or family-dropping fallback.
The joint oracle and one-parameter analytic fits test the optimizer separately
from the conditional probability kernel's independent references.

Serial and two-process real-CLI fits produced identical bundles. Gene-weighted
likelihoods reconstructed saved totals. Flat/unidentified/boundary fitted
values and dated point trees are withheld; numerical solutions and profiles
remain distinct in JSON. Requesting an unresolved `--tree-out` fails before
replacing outputs. An input/profile alias and an injected late JSON writer
failure preserved all six existing bundle files without residual staging
files. Forged input attachment properties could not move supplied tip ages.
Legacy D+L/reference cases and fixed-MSC schema/round-trip cases passed.

Early small study smoke runs found two study-adapter errors: passing a
`StringIO` to NWKIT's raw-text tree API and using the wrong SpeciesParser
keyword. Both were fixed before the full run; their failure files remain in
`/tmp/nwkit-msc-fit-smoke-20261002` and its `-b` sibling. A fresh `-c` smoke
run completed. Scientific inputs, bounds and recovery criteria were not
changed to obtain the full-run results.
