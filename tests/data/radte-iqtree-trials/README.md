# IQ2MC line-search trial regression

Four 150-codon sequences generated by GeneGalleon's
`test_native_tree_dating._fixture`, with NumPy seed 91 and the GY94 simulation
model. The gene tree is defined in `test_radte_iqtree_trials.py`.

The `GY+F3X4+R4` exact dating fit proposes very short positive branches during
SLSQP line search. On amd64, IQ-TREE can export a finite likelihood but an
infinite gradient and a nonfinite Hessian at a trial that the line search would
reject. Objective-only evaluation must not require those unused derivatives.
Accepted points still require finite derivatives; neither branch lengths nor
model parameters are changed to make the export pass.
