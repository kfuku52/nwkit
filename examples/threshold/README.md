# Threshold diagnostic pilot

These fixed-threshold prior-predictive experiments test computational diagnostics,
not a null-hypothesis test. Data are generated by direct ancestral Gaussian draws
independent of the MCMC implementation. The sampler's retained draws are observed
read-only to calculate equal-tail 95% liability intervals and posterior CDFs at
simulated true values; this does not add interval columns to the product output.

```sh
PYTHONPATH=. python tools/validate_threshold_asr.py \
  --replicates 8 --samples 400 --burnin 200 \
  --output examples/threshold/diagnostic-pilot.json
PYTHONPATH=. python tools/validate_threshold_asr.py \
  --replicates 2 --samples 2000 --burnin 1000 \
  --output examples/threshold/diagnostic-pilot-longer.json
```

There are four chains in both runs. The longer run reuses the first two generated
datasets and MCMC seeds in each case. It increases both burn-in and retained
samples, so this is a computation-budget comparison, not an isolated thinning or
burn-in experiment. The scripts record source hashes and reject source changes
while running. Each JSON retains every replicate, including diagnostic failures.

| Case | Full diagnostic pass, 400 draws/chain | Full diagnostic pass, 2,000 draws/chain | Root 95% interval coverage, short run |
|---|---:|---:|---:|
| Balanced | 0/8 | 2/2 | 8/8 |
| Pectinate/unequal branches | 0/8 | 1/2 | 8/8 |
| Short terminal branches (0.01) | 0/8 | 0/2 | 8/8 |
| Polytomy/unequal branches | 0/8 | 2/2 | 8/8 |
| Fixed ordinal, rare upper category | 0/8 | 1/2 | 7/8 |
| Missing tip | 0/8 | 2/2 | 8/8 |

All 48 short and 12 longer fits returned results without a computation error.
The short run deliberately has too little information for the absolute
probability MCSE requirement in many cases: a probability near 1/2 needs roughly
2,500 independent draws for MCSE 0.01, more than its 1,600 raw draws. Diagnostic
failure therefore does not mean the point estimate is incorrect. Coverage does
not imply convergence either.

In the longer run, the short-terminal-branch cases still have maximum R-hat
about 1.08 and 1.21 and minimum ESS about 40 and 14. The other two nonpassing fits
have a probability-precision failure and an unresolved rare category. These are
actual sampled-chain findings, distinct from synthetic drift counterexamples.
They establish a need for more computation or a better mixing kernel for those
cases; they do not establish systematic posterior bias. No threshold was relaxed
to make them pass.

Eight replicates per cell cannot estimate 95% coverage precisely: even 8/8 has
an exact 95% binomial interval of approximately [0.631, 1]. The longer run's
12/12 root coverage is also not a calibration guarantee. Ancestors within the
same tree are correlated and are not pooled as independent binomial replicates.
There are no passing short-run fits, so their pass-conditioned coverage is
unavailable, rather than zero. Exact binomial intervals and denominators are in
the JSON. This pilot does not meet a 1,000-replicate per-cell coverage acceptance
criterion and should not be described as doing so.

For a budgeted larger validation, retain every run, use root outcomes or
replicate-level clustering for uncertainty, predeclare tolerances and test both
reference-posterior error and diagnostic pass/fail rates. Free ordinal thresholds
have an improper prior, so their prior-predictive SBC cannot reuse this generator;
independent integrated posterior checks cover that setting instead.

See [the diagnostic definitions](../../THRESHOLD_DIAGNOSTICS.md) for references,
constant/rare-category handling and the output contract.
